Miu · Voice & Dialogue

Nicht Plattform-Konfiguration allein – ein hands-on gebauter Voice- & Dialogue-Stack: Multi-Turn mit strukturiertem Memory (Episoden und Themen sind verknüpft – nicht nur „ähnliche“ Treffer), Speech-Pipeline (ASR → Agent → lokal Qwen3-TTS MLX, Stimme miore), REST/SSE an Live-Backends, Observability auf Turn-Ebene. Zielbild: Full-Duplex bei niedriger Latenz trotz großem Kontext (Interaction Models · Thinking Machines).

Was der Stack konkret abdeckt

  • Agent building end-to-end: Multi-Turn-Flows, Dialogue State, Fallback & Escalation – nicht nur UI-Konfig einer Voice-Plattform.
  • Strukturiertes Memory (Cascade): Zusammengehörige Episoden hängen am Index – z. B. Schadenfall → Erstaufnahme → Besichtigung → Regulierung. Das ist Context über lange Sessions, nicht nur Vektor-Suche nach ähnlichem Text.
  • Speech in Produktion · owned TTS: LiveKit; STT → Agent → Qwen3-TTS auf Apple Silicon (MLX), Voice miore; Latenz/Feel als Ziel; REST/SSE + async Fehlerpfade; Turn-Analytics (MMA/ERIP).

Dialogue Stack

Vier Schichten · ein laufendes System

Ein Postgres-basiertes Memory-Haus: Kurzkontext, Identität, episodische Historie, Turn-Stempel. Zusammengehörigkeit steckt in Verknüpfungen – nicht nur in „ähnlichen“ Embeddings.

  1. Session / Kurzkontext Chat-Verlauf

    Aktuelle Turns und Summaries – Dialogue State für den laufenden Call/Chat.

  2. Agent-Identität Core Memory Blocks

    Beschriftete Blöcke mit Limit. Manche immer im Prompt, andere nur bei Kanal, Keyword oder Regime – wiederverwendbare Agent-Patterns.

  3. Langzeit · episodisch Archival Episodes

    Durchsuchbare Episoden mit Datum, Tags, Embeddings – Kontext über Sessions hinweg (nicht nur Similarity-Mix).

  4. Observability MMA Events

    Turn-Stempel (Kurzfassung, ERIP, Topics). Grundlage für Quality-Regression, Drop-off-Lesen und Root-Cause – nicht nur Chat-Log.

Zwei Hebel für Agent-Qualität: Zusammengehörigkeit routen, und lernen ohne Amnesie.

Cascade · Memory-Index

Zusammengehörigkeit statt nur Similarity

Cascade ist der Index auf dem Memory: Episoden, Themen und Tage sind verknüpft. „Schadenfall Sturm 2024“ öffnet Erstaufnahme, Besichtigung, Regulierung – der Agent findet, was zusammengehört, nicht nur Text der ähnlich klingt.

Tools: cascade_search · Kanten in Postgres · anschlussfähig an Intent-/Slot-Flows ohne Amnesie.

Learning Agent · Continuous Improvement

Lernen auf mehreren Takten

Hintergrund-Editor: ~10 Turns Core, ~50 Archival. Bewährte Dialogue-Patterns bleiben stabil. Nested-Learning-Idee – eigene Mechanik, kein Modell-Port.

  1. TurnMain Agent
  2. ÷10LA · Core
  3. ÷50LA · Archival
  4. EODThemengraph
  5. WocheRollup → Core

Geschützte Regale gesperrt · riskante Writes mit Approval-Gate · Fallback/Escalation als Design.
