Miu · Lernen & Erinnern

Nicht „Chatbot mit Suche“. Ein Companion, der Wissen über Tage verarbeitet: strukturierter Gedächtnis-Index, episodische Langzeit-Erinnerung, und ein Lern-Agent, der Neues einbaut – ohne das Alte plattzuwalzen.

Warum das für Enterprise / Allianz interessant ist

  • Continual Learning statt Amnesie: Neues Wissen auf mehreren Zeitskalen – ohne jedes Update die Identität zu überschreiben (Nested-Learning-Idee, angepasst).
  • Struktur statt nur Similarity: Cascade ist ein Graph-Index („Urlaub 2025“ → was gehört zusammen). Vektor-Suche findet Ähnliches; der Index findet Zusammengehörigkeit.
  • Episoden + Steuerung: Langzeit-Episoden mit Datum/Tags. Metakognition (MMA) stempelt Turns. Riskante Writes nur nach HITL – Governance im Loop.

Architektur

Vier Schichten · ein Haus

Alles in einem Postgres-Haus. Kurz: was gerade passierte · wer Miu ist · was früher war · wie der Turn gestempelt wurde.

  1. Kurzkontext Chat-Verlauf

    Letzte Turns und Zusammenfassungen. Was gerade im Raum passiert ist.

  2. Arbeits-Identität Core Memory Blocks

    Beschriftete Blöcke mit Zeichenlimit. Manche immer im Prompt – manche nur bei Kanal, Keyword oder Regime.

  3. Langzeit · episodisch Archival Episodes

    Durchsuchbare Episoden mit Datum, Tags, Embeddings. Das ist die episodische Schicht – „was damals passiert ist“.

  4. Metakognition MMA Events

    Stempel auf Chat-Nachrichten (Kurzfassung, ERIP, Topics). Nicht die private Erinnerungs-Injekt – die kommt davor als Kontext.

Index & Lernen

Cascade + Learning Agent

Zwei Hebel: finden was zusammengehört, und lernen ohne Amnesie.

Cascade

Gedächtnis als Index

Wie Menschen erinnern: „Ich war 2025 im Urlaub“ ist der Schlüssel. Aufklappen – und Reisen, Leute, Momente hängen am Regal. Episoden → Themen → Tage → Wochen. Kanten schlagen reinen Cosine-Mix.

Tools: cascade_search · Kanten in Postgres · Blätter bleiben bei Rollups.

Learning Agent

Lernen auf mehreren Takten

Hintergrund-Editor: alle ~10 Turns Core, alle ~50 Archival. So bleibt, was schon „geklickt“ hat. Design-Anleihe an Google Nested Learning + MIRAS/Titans – angepasste Mechanik, kein Modell-Port.

  1. ChatMain Agent
  2. ÷10LA · Core
  3. ÷50LA · Archival
  4. EODThemengraph
  5. WocheRollup → Core

Verbotene Regale (Identität, gewisse Summaries) bleiben für den Learning Agent gesperrt. HITL für riskante Writes.
