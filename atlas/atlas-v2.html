L1 · Lived recall

Lived recall

The mechanism in one example turn: rise into context → posted reply → MMA stamps both chat sides.

Follow the red thread once. Mid-thread on markets and people. A question pulls an episode from months earlier. Bridge Rise loads a sparse thought into the agent’s context. That is not the Discord reply. After thinking, the agent sends a real answer. Then MMA stamps both sides of the chat. The lines below are an illustrative, condensed example, not a transcript.

UserWhy does volatility clustering feel like relational intensity?
In context · glassThat bridge again. Markets and people both bunch when the regime flips.
Agent reply · postedBecause both are contagion under stress: shocks cluster, and hard feelings do too. Same gut as that June afternoon when embodiment clicked and the curve suddenly felt beautiful.

We call the context inject Bridge Rise. Cue → rarity → opacity. Glass = one clean thought in context. Amplify = one temporal or felt anchor with source binding. The reply is a separate act. Familiarity alone never amplifies.

L2 · Compress

Learning Agent · compress · summaries

Learning Agent. Background mini-loop. Edits Main-agent core (and archival on its cadence). Does not delay the Discord reply when Nested Learning runs in the background.

Conversation summary. Separate pipeline from the Learning Agent. When history grows past a threshold, a window summary keeps the short context sane.

Cascade compress. EOD builds the theme graph from the day. Weekly and monthly rollups write back into core summary blocks. Leaves stay on the graph.

L1 · Memory

Memory · how it holds

Recruiter shorthand maps like this. Short context is recent chat. Working identity sits in core blocks (not all blocks every turn). Long-term episodes live in archival. MMA stamps metacognition on top. Deep flows open below.

Memory index. Inspired by how people remember: “I was on holiday in 2025” is the index key. Open that shelf and the trips, people, and moments hang together. Cascade is that index as a real graph: episodes → themes → days → weeks.

Books in pages. Hortus walks long material page by page, with bookmarks and archive. Finish a book across turns. Not one giant paste into the prompt.

L2 · Cascade

Cascade · find path + why edges beat vectors alone

Ask for a season, a KW, a place, a person. Vector search finds similar text. The index finds what belongs together.

Why the graph matters. Similarity alone mixes hubs. Edges carry “this theme met that person on that day.” Soft and hard links (hard gated by Myzel HITL) keep the structure honest. That is what saves the house when the archive gets huge.

Compress without amnesia. Week and month summaries climb into core. Day leaves stay searchable. Rollup densifies. It does not delete the shelf.

L2 · Find

Find · search workflow

Grep-first facts. When the question is “when did we say X,” circle grep and chronological search beat vague vector dumps.

Gnostic. Convergence / involuntary spark lane. Separate from Bridge Rise (lived inject).

Canon check. Serious claims prefer at least two signals (for example conversation search plus cascade), not a single hit.

L2 · Core blocks

Core blocks · create, gate, version, drift

The agent lays down its own working shelves. Each block has a character limit (default 2000). Edits can leave a short change line. Versions compare what shifted. Some blocks are read-only or forbidden for the Learning Agent.

L1 · Voice & face

Presence and voice · Faces

Three face centers (Tabby, OGU, Miu Face). One storyboard source of truth on the Mini. Phones subscribe over LiveKit. They do not own the FSM.

Scenes are idle loops (stand, couch, light sleep, deep sleep). Edges are one-shot intro or outro MP4s that bridge poses. FaceArbiter holds speak sessions until tts_done, rotating pose-matched talk / lip clips while audio plays. That is live mouth motion on the storyboard path, not audio-driven lipsync yet.
